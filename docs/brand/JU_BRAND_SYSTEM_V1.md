# JU Brand System V1 — Signal System

Status: **PROPOSED / Founder-approved direction, implementation reference**

## 1. Purpose

This is the shared visual language for JU-branded products.

Apply this system to projects whose product name begins with **Ju** (for example JuPortal, JuQode, JuTell, JuDoctor, JuControler, JuMiner), unless the Founder explicitly opts a product out.

The goal is family resemblance, not cloned websites.

**Shared DNA, different products.**

## 2. Core idea

**FROM SIGNAL TO TOOL**

A human intention becomes a signal.  
The signal becomes AI work.  
The work resolves into a tool a human can understand.

JU motion language:

**APPEAR → ASSEMBLE → RESOLVE**

## 3. Brand character

JU should feel:

- dark
- editorial
- retro-future
- pixel / dot / signal
- human + AI
- precise
- experimental, but readable
- technical, but not developer-exclusive

Avoid:

- gamer / 8-bit arcade UI
- neon cyberpunk overload
- glossy Web3 cards
- generic SaaS gradients
- blue/cyan/violet JuContentBox language
- cute robot mascots
- copying JuPortal layout into every product

## 4. Core colors

- JU Black: `#0B0B0A`
- JU Panel: `#11110F`
- JU Line: `#2B2B28`
- JU Paper: `#F2F1EA`
- JU Muted: `#8F9088`
- JU Signal Lime: `#D8FF4F`
- JU Signal Mint: `#8DF6DC`

Lime is a signal, not a fill. Use it sparingly for active state, CTA, signal nodes, and product-specific accent moments.

## 5. Primary symbol

Primary brand symbol: **JU Signal Dot Mark**.

It is a dot-matrix JU signal with one lime signal node.

Rules:

- the dot language is the brand constant
- the exact product icon must not be identical across all products
- each Ju product mutates the shared dot system with a product-specific motif
- the lime node remains recognizable as the JU signal

Base asset:

`docs/brand/assets/JU_SIGNAL_DOT_MARK_V1.svg`

## 6. Product icon family

Every Ju product icon uses the JU Signal grammar, but must remain distinguishable.

Examples:

- **JuPortal** — pure Signal Dot Mark / brand-home treatment
- **JuQode** — signal mark + code/bracket or construction motif
- **JuTell** — signal mark + message/diff/explanation motif
- **JuDoctor** — signal mark + pulse/diagnostic motif
- **JuControler** — signal mark + control/grid/node motif
- **JuMiner** — signal mark + layer/scan/extraction motif

Do not simply recolor one identical icon.

## 7. Website intensity

### JuPortal — Brand Home / 100%
May use:
- large signal object
- strongest motion
- Founder pixel portrait
- large editorial typography
- full brand narrative
- side rail as a dominant element

### Product websites — 40–60%
Use:
- shared colors
- Signal Dot Mark
- pixel/dot transitions
- editorial labels
- lime CTA
- optional side rail if it helps the product
- restrained motion

Do not copy the JuPortal hero or full story structure.

### Utility / tool interfaces — 20–40%
Use:
- token system
- icon family
- signal states
- typography
- subtle dot/pixel texture
- functional UI first

## 8. Founder portrait

The Founder portrait is **not** a universal JU icon.

Use only on:
- JuPortal
- JU brand storytelling
- selected campaign/brand media

Treatment:
- no profile-card rectangle
- no social-avatar look
- dissolve into hero/background
- pixel / dot / ASCII texture
- partial face or crop
- subordinate to the JU symbol

Do not commit the raw Founder portrait to public product repos unless the Founder explicitly approves publication.

## 9. Typography

Use:
- large Korean headline
- tight display tracking
- deliberate line breaks
- small uppercase English metadata
- optional monospace microcopy

Typography should work as a visual object, not just body text.

## 10. Motion

Shared JU motion:

1. signal appears
2. dots / text / states assemble
3. real product or result resolves

Avoid generic fade-everything-in animation.

Respect `prefers-reduced-motion`.

## 11. Navigation

JU does **not** require every site to have the same layout.

Side rail is preferred for:
- brand/editorial sites
- multi-section product storytelling
- JuPortal

A normal compact product nav is acceptable when better for the tool.

Shared identity matters more than identical navigation.

## 12. JuContentBox separation

JuContentBox has its own catalog identity:
- navy
- cyan / blue / violet
- gradient / glow
- marketplace / library density

Do not pull that system into JU Signal websites.

JU Signal is:
**BLACK / PAPER / LIME / DOT / PIXEL / EDITORIAL / HUMAN / SIGNAL**

## 13. Email / closing CTA

Brand-heavy sites may end with a dark email CTA.

Recommended copy:

> 지금, JU의 다음 소식을 가장 먼저 받아보세요.

> 새로운 기능, 제품 업데이트, 그리고 더 큰 가능성에 대한 소식을 전해드립니다.

CTA: **알림받기**

## 14. Implementation rule

When building or redesigning a Ju* product:

1. read this document
2. read `skills/ju-brand/SKILL.md`
3. use the shared symbol asset
4. create a product-specific icon variant
5. preserve the product's functional needs
6. prove the result is recognizably JU but not a JuPortal clone
