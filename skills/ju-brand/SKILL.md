# JU Brand Skill

Use this skill whenever you are designing or implementing a **Ju-prefixed product** (for example JuPortal, JuQode, JuTell, JuDoctor, JuControler, JuMiner).

## Goal

Make the product immediately recognizable as part of JU while keeping its own product identity.

## Mandatory shared DNA

- JU Black `#0B0B0A`
- JU Paper `#F2F1EA`
- JU Signal Lime `#D8FF4F`
- JU Signal Mint `#8DF6DC`
- pixel / dot / signal language
- editorial typography
- Human → AI → understandable result narrative
- motion language: **APPEAR → ASSEMBLE → RESOLVE**
- use the JU Signal Dot Mark as the parent visual grammar

Reference:
- `docs/brand/JU_BRAND_SYSTEM_V1.md`
- `docs/brand/assets/JU_SIGNAL_DOT_MARK_V1.svg`
- approved JU dark concept image supplied with the current design handoff; commit it as a repository reference before implementation if it is not already present

## Website rule

Do not copy JuPortal page-for-page.

Choose the visual intensity:

- **Brand home**: 100%
- **Product marketing site**: 40–60%
- **Tool / app UI**: 20–40%

Keep functionality first on product/tool surfaces.

## Icon rule

Every Ju* icon must be related, but not identical.

Start from the Signal Dot grammar, then add one product-specific motif.

Examples:
- JuQode: code/build
- JuTell: explain/message/diff
- JuDoctor: health/pulse/diagnostic
- JuControler: control/node/grid
- JuMiner: scan/layer/extract

Never ship five products with the exact same icon and only different text.

## Founder portrait rule

The Founder portrait is optional and mainly for JuPortal / JU brand storytelling.

Never use it as:
- a universal app icon
- a generic avatar
- a boxed profile card

If used:
- integrate it into the background
- use pixel/dot/ASCII treatment
- keep it secondary to the brand symbol
- do not publish the raw photo unless explicitly approved

## Motion rule

Prefer:
- dot gathering
- signal travel
- text assembly
- pixel reveal
- UI/result resolving

Avoid:
- generic mass fade-in
- excessive glow
- arcade/game effects

Respect reduced motion.

## JuContentBox separation

Do not reuse JuContentBox's:
- cyan/blue/violet gradient identity
- 3D/glow marketplace language
- dense catalog visual system

JU Signal must remain dark, editorial, human, and signal-driven.

## Completion check

Before reporting complete, answer:

1. Does it look unmistakably JU?
2. Does it still look like this specific product?
3. Is the icon related to the JU Signal family but unique?
4. Are lime/mint restrained?
5. Is motion APPEAR → ASSEMBLE → RESOLVE?
6. Did you avoid cloning JuPortal?
7. Did you avoid JuContentBox's visual identity?
8. Is mobile still functional and readable?

If any answer is no, keep working.
